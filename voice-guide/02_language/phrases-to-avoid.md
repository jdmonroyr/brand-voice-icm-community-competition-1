# Phrases to avoid

If it sounds like a dog toy packaging or a corporate email template, it's not us.

## The checkable list
Every specific banned phrase and pattern — cutesy wordplay, corporate deflection, hedging, hard-sell pressure, sign-offs — lives in one place now: [rules.md](rules.md). That's the file the `brand-app/` checker is compiled from, so it's also the file to edit when a new bad phrase turns up. This page stays the framing; that one stays the list.

## Judgment calls that aren't simple phrase matches
- Exclamation points stacked for enthusiasm ("So excited!! Can't wait!!") — a counting rule, covered in [mechanics.md](mechanics.md), not a fixed phrase
- Baby talk about the dog ("who's a good boy" as brand copy — fine from a groomer in person, wrong in writing) — too context-dependent to flag mechanically; a human call
- Any line that explains what a mobile groomer is to someone who already booked one — a structural issue, not a phrase — flag it by eye

## About competitors
- Never name a specific competitor
- Never use "unlike other groomers" as a setup for a jab
- See [competitor-mentions.md](../03_scenarios/competitor-mentions.md) for how to draw the contrast instead

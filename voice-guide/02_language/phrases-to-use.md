# Phrases to use

Language that sounds like us. Not a script — a register to write in.

## Describing the service
- "We come to you."
- "Groomed in the driveway, not a kennel down the street."
- "No cage, no car ride, no waiting room."
- "Your dog's whole day is: went outside, got a haircut, came back in."
- "We text you the second we're done."

## Describing the dog's experience
- "Calm," "comfortable," "at home" — over "happy" as a default (happy is fine, just not the only word)
- "Never leaves your driveway"
- "One dog, one groomer, no other dogs in the room"

## Describing ourselves
- "We've done this a long time." (plain, not falsely modest, not boastful)
- "We'll tell you straight" (for anything about a dog's coat, behavior, or health)
- "Fully booked" stated as fact, not a brag — it's information, not a flex

## Sign-offs and small talk
- "See you [day]."
- "Text if anything changes."
- Using the dog's name constantly — it's the one place specificity always reads as warmth, not gimmick

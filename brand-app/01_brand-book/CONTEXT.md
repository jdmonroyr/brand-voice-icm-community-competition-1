# 01_brand-book — translate voice into a visual system

One job: turn the voice pillars into color, type, and layout decisions concrete enough for `02_build` to work from without guessing.

## Inputs
- Reference (every run): ../../voice-guide/01_identity/who-we-are.md
- Reference (every run): ../../voice-guide/01_identity/voice-principles.md

## Process
1. Read the identity layer. No existing visual assets exist for Ruff Cuts (confirmed with Dana) — this is a proposal, not a transcription.
2. Derive a palette, type pairing, and layout concept from the same five pillars that govern the writing (warm-not-cute, confident-not-corporate, respect the reader, clearly different not dismissive, calm is the product) and from the concrete subject (a van, driveways, grooming tools, Austin) rather than generic "pet brand" or "premium service" defaults.
3. Write the system down as named tokens a build stage can implement directly — not moodboard language.

## Outputs
- brand-book.md → output/

## Human check
Does the palette read as "friend who happens to be an expert" — warm and confident, not cutesy (no pastel pinks/blues) and not corporate (no default SaaS blue/purple)? Edit hex values or type stacks directly in the output file before `02_build` reads it.
